# Mike's Sunday Spin Show

Drift game set on Plot 10770, Kafue Road, Lusaka.

Full source is in the `src/` folder. The BMW 335i mesh (`public/models/bmw.glb`, Mike Pan, CC-BY) is too large for this text commit — export it from the Blender file and drop it at `public/models/bmw.glb`.

## Run

```bash
npm install
npm run dev
```

W/S gas/brake, A/D steer, Space handbrake. Phone: left stick + Spin.
